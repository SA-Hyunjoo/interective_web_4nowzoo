# chainsaw man 검증 기록

## 자동 검증 완료

- `npm run build`: TypeScript 검사 및 프로덕션 빌드 통과.
- `node --test tests/chainsaw-model.test.mjs tests/chainsaw-starter.test.mjs tests/chainsaw-pose.test.mjs`: 5개 테스트 통과. 얼굴 맞춤 검사는 합성 좌표를 이용하며 실제 웹캠 검사와 다름.
- 테스트 범위: 머리 톱날의 전방 돌출, 양팔 모델 범위, 톱니 행렬의 유효성, 애니메이션 중 geometry/material 재사용.
- 변신 후 화면 양옆에서 셀 셰이딩 괴물·가상 남성 캐릭터가 교대로 등장. 최대 3명 활성화.
- 팔 전기톱 끝의 실제 화면 궤적이 초당 360px 이상으로 적을 통과할 때만 절단. 팔·목·양다리·머리·몸통 파편 8개와 혈액 입자 42개 생성, 짧은 절단음은 촬영 오디오에도 합성.
- 적·신체 조각·혈액은 고정 개수 풀로 재사용하며 화면을 나가면 모두 초기화.
- 기존 `playroom-webcam-captures`, `playroom-balloon-captures` DB 이름과 버전, 기존 데이터 읽기/삭제 경로 유지. 데이터 삭제·마이그레이션 수행하지 않음.

## 실제 기기 검증 미완료

연결 가능한 Browser가 없어 웹캠, 화면 렌더링, 실제 저장 파일 재생, 체감 성능/발열은 확인하지 못함. 위 자동 검사로 실제 카메라 검증을 대체할 수 없음.

### 수동 확인 순서

1. `npm run dev`로 실행하고 `/#chainsaw`로 이동. 시작 버튼에서 카메라 권한 허용.
2. 정면·좌우 회전·위아래 기울임에서 머리 위치, 크기, 돌출 톱날과 턱의 겹침 확인.
3. 얼굴을 0.2~0.5초 가린 뒤 다시 노출. 급격한 위치 이동이 없는지 확인. 0.65초 이상 가리면 머리 효과가 사라져야 함.
4. 머리 위 3D 고리와 주변 42px 여유 영역을 양손 각각 핀치. 28~45px 아래로 당기면 한 번만 변신. 계속 잡아 움직여도 재작동하지 않아야 함. 고리가 화면 상단 내비게이션 아래로 보정되는지 확인.
5. 변신 순간 고리와 체인이 사라지고, 기존 위치에서 다시 핀치해도 반응하지 않아야 함. 다시 시작은 다른 예제로 이동 후 복귀해 카메라 시작. 손이 잠깐 추적되지 않을 때 오작동하지 않는지 확인.
6. 양손 이동·교차·카메라 접근/후퇴에서 톱날의 방향과 크기를 확인.
7. 변신 순간 약 0.5초 성장, 불꽃·파편·붉은 혈액 입자, 순환 톱니, 시동/작동음 확인. 화면을 떠나면 소리가 끝나야 함.
8. PHOTO 촬영 후 ARCHIVE에서 확대·다운로드 확인. VIDEO는 변신 전부터 녹화하여 변신/해제 사운드까지 재생 확인.
9. 새 사진·영상으로 삭제를 확인하되 기존 촬영물은 지우지 않음. 새로고침 후 기존/새 촬영물 유지 확인.
10. 모든 예제에서 하단 세 버튼 확인. 다른 예제로 이동하거나 탭을 숨기면 카메라/엔진 중단, 진행 중 녹화 저장 확인.
11. 모바일 세로·가로 회전, 3분 연속 실행으로 프레임 안정성과 발열을 확인.

## 구현 범위와 제한

- Three.js 깊이 버퍼로 3D 머리·톱날·턱·팔 모델 사이 가림 처리. 실제 신체나 주변 물체의 픽셀 단위 분리/가림을 위한 세그멘테이션은 포함하지 않음.
- 머리 위 시동 고리, 연결 체인, 불꽃·파편도 실제 3D 메시 사용. 카메라 영상과 3D 렌더링 결과만 최종 2D 캔버스에 합성해 기존 촬영 경로 유지.
- 사운드는 저음량 Web Audio 합성 효과이며, 애니메이션의 원본 음원을 사용하지 않음.
- 렌더링 목표 30fps, 추적 간격 약 40~100ms 적응 조절, 모델/재질/입자 풀 재사용. 실제 성능은 기기에 따라 달라짐.
- MP4 MediaRecorder 지원 시 MP4, 미지원 브라우저는 기존처럼 WebM 저장. 확장자만 MP4로 바꾸지 않음.
- 녹화 크기는 시작 시 고정. 화면 전환/탭 숨김 시 녹화를 종료해 다른 예제의 영상과 이전 효과음이 섞이지 않게 처리.
