# 동물의 숲

상단 **12 동물의 숲** 탭 또는 `/#animal-forest`에서 엽니다.

- 드래그: 지구본 둘러보기. 휠 또는 +/− 버튼: 확대·축소. 처음 풍경: 전체 지구본으로 복귀.
- 첨부 레퍼런스의 잎이 겹친 나무, 부드러운 초록색 잔디, 흙빛 강둑과 밝은 물길을 Three.js 메시로 구현했습니다.
- 구 전체의 좌표로 지형과 물길을 계산하며, 동일한 맵 타일을 반복하지 않습니다. 고정 시드로 매번 같은 세계를 만들고 나무 종류·크기·회전과 꽃·풀·돌 배치를 달리합니다.
- 침엽수, 활엽수, 과일나무, 분홍 숲, 강과 호수, 꽃, 풀, 버섯, 바위, 작은 집, 다리, 피크닉 자리가 있습니다.
- 초기 화면은 나무를 포함한 구 전체가 들어오도록 화면 비율에 맞춥니다. 가까이 확대하면 일부가 화면 밖으로 나갈 수 있으며 처음 풍경으로 복구할 수 있습니다.
- 기존 PHOTO/VIDEO 캡처를 연결했고, 탭을 떠나면 렌더링과 GPU 자원을 해제합니다.
- 구현: `src/animal-forest.ts`, `src/animal-forest.css`. 외부 모델·이미지 다운로드나 새 npm 의존성은 없습니다.

확인 범위: TypeScript 및 프로덕션 빌드, 데스크톱 Chrome 화면, 드래그/휠/초기화/탭 재진입. 전체 플랫폼 및 실제 장치 성능 최적화는 후속 작업입니다. 개발 서버는 실행하지 않았습니다.

## 주민 입주

화면 하단 **입주하기**를 누르면 왼쪽 카메라와 오른쪽 이미지 선택 영역이 열립니다. 파일 선택 또는 드래그 앤 드롭으로 이미지를 넣으면 카메라가 준비된 시점부터 **5초 카운트 후 한 장을 촬영**합니다. 얼굴과 신체가 잘 보이고, 입력 이미지의 중앙에 형체 하나가 크게 있는 사진이 가장 잘 동작합니다.

1. EfficientNet-Lite0로 이미지의 종류를 분류하고 MagicTouch로 중앙 형체의 외곽선을 추출합니다. 투명 PNG는 알파 경계를 사용합니다.
2. 사람·고양이·강아지·토끼·곰·새·개구리·사슴·코끼리·돼지·문어의 형태군과 이미지의 비율/면적/시드를 조합해 둥근 미니어처를 만듭니다. 기타 물체는 행별 외곽선으로 두께와 둥근 모서리가 있는 입체를 만듭니다.
3. 촬영한 사진은 기존 Selfie multiclass 모델로 사람 내부만 자릅니다. PoseLandmarker로 얼굴, 어깨, 팔꿈치, 손목, 골반, 무릎, 발목을 찾아 부위별 텍스처를 배치합니다. 배경 픽셀은 RGB까지 제거하며, 텍스처의 빈 곳은 사람 영역 안의 색으로 채웁니다. 보이지 않는 팔다리는 몸통 텍스처로 보완합니다.
4. 완성한 주민을 중앙에서 크게 약 2.7초 보여준 뒤 약 2.2초 동안 줄여 지구본에 배치합니다. 주민은 구 표면을 따라 랜덤하게 방향을 바꾸고 쉬어 가며 걷습니다. 강·나무·집·다른 주민은 피합니다.

### 현재 구현 범위

- 브라우저 내부의 인식 + 절차적 모델링 MVP입니다. 임의의 사진을 정밀한 3D 메시로 복원하는 생성형 image-to-3D 서비스는 연결되어 있지 않습니다. 미등록 종류, 복잡한 배경, 여러 형체, 사진에 없는 뒷면/가려진 부위는 정확히 재현하지 못합니다. 물체의 구멍이나 분리된 조각도 단순화합니다.
- 레퍼런스처럼 큰 머리와 짧은 팔다리로 비율을 통일합니다. 생성 모델의 품질과 사람 사진의 원근/포즈 때문에 UV 매핑은 근사이며, 정면·밝은 조명·전신 촬영이 유리합니다.
- 카메라는 촬영 완료, 취소, 브라우저 탭 숨김, 게임 이동 시 꺼집니다. 카운트 중 취소하면 촬영/입주하지 않습니다.
- 이미지를 외부로 업로드하지 않습니다. 원본 촬영 사진은 저장하지 않고 사람만 자른 캔버스를 이 페이지의 메모리에 보관합니다. 최대 24명이며 게임 탭을 오가면 유지되지만 **페이지를 새로고침하면 초기화**됩니다.
- 초기 입주 시 인식 모델을 준비하므로 첫 결과까지 시간이 걸릴 수 있습니다. 같은 게임 화면의 후속 입주는 모델을 재사용합니다.
- 촬영/분석 오류는 재촬영 버튼으로 복구할 수 있습니다. HEIC/HEIF를 해독하지 못하는 브라우저에서는 JPG/PNG를 사용하세요.

구현은 `forest-residents.ts`(UI·수명·입주·보행), `forest-resident-vision.ts`(분류·분할·포즈), `forest-resident-model.ts`(메시·부위별 텍스처), `forest-residents.css`로 나눕니다.

### 이번 확인

개발 서버를 실행하지 않고 빌드 파일을 임시 Chrome에 주입했습니다. MediaPipe 공식 예제 인물 사진을 카메라 스트림으로 사용하여 실제 로컬 분류·MagicTouch·HumanSeg·Pose 모델로 사람형과 고양이형 입주를 확인했습니다. 5초 카운트, 결과 표시, 입주 완료, 카메라 트랙 종료, 게임 탭 재진입 후 주민 유지, 카운트 중 취소를 확인했습니다. 실제 웹캠 촬영 품질과 모든 플랫폼 검증은 수행하지 않았습니다.
드래그 앤 드롭한 투명 물건 이미지의 실루엣 입체 생성과 두 번째 주민 입주도 확인했습니다. 마지막 브라우저 확인에서 페이지 실행 오류 0건, 카메라 트랙 모두 종료, 취소 후 주민 수 유지 결과를 얻었습니다.
