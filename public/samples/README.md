# 샘플 파일 넣는 방법

이 폴더에 아래 이름으로 WAV 또는 MP3 파일을 넣으면 샘플러가 자동으로 불러옵니다.

```text
q.wav 또는 q.mp3
w.wav 또는 w.mp3
e.wav 또는 e.mp3
a.wav 또는 a.mp3
s.wav 또는 s.mp3
d.wav 또는 d.mp3
z.wav 또는 z.mp3
x.wav 또는 x.mp3
c.wav 또는 c.mp3
```

- 같은 키의 WAV와 MP3가 모두 있으면 WAV를 먼저 사용합니다.
- 파일이 없거나 읽을 수 없으면 해당 키의 기본 내장 사운드가 재생됩니다.
- 파일을 교체한 뒤에는 브라우저를 새로고침하세요.
