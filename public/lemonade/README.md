# Lemonade 레몬 이미지

이 폴더에 레몬 이미지를 넣으면 게임 화면에서 자동으로 사용합니다.

```text
lemon-1.png
lemon-2.png
lemon-3.png
lemon-4.png
lemon-5.png
lemon-6.png
```

- PNG, JPG, WEBP 형식을 지원합니다.
- 투명 배경 PNG를 권장합니다.
- 파일이 없으면 기본 레몬 일러스트가 표시됩니다.
- 이미지를 추가하거나 교체한 뒤 브라우저를 새로고침하세요.

손 추적에 필요한 MediaPipe 모델과 Wasm 파일도 이 폴더에 함께 보관됩니다. 지우지 마세요.
